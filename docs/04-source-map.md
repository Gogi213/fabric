# 04. Карта источников: откуда ниша берёт контент

**Дата:** 2026-09-30
**Окно:** 2026-09-15 … 2026-09-29 (две недели)
**Скрипт:** `tools/sources3.py`, `tools/uncertainty.py`
**Данные:** `data/sourcemap.json`, `data/links.json` (4464 поста, 37 каналов),
`data/uncertainty.json`

> **Про интервалы.** Для долей доменов интервал считается **бутстрэпом
> по каналам в пуле**: каналы перевыбираются, доли пересчитываются.
> Доли «медиана по каналам» — **другая величина** и в таблицах
> не используются.

## 1. Что измерялось

Для каждого поста из двухнедельной выборки извлечены четыре типа
upstream-ссылок:

| Тип | Поле | Что показывает |
|---|---|---|
| Прямая ссылка | `links[]` | домен-источник |
| Форвард | `fwd_name`, `fwd_url` | перепечатка из другого канала |
| @упоминание | `mentions[]` | канал упомянут в тексте |
| Ответ | `reply` | канал отвечает на другой канал |

Домены сгруппированы в 14 корзин по типу источника.

## 5. Форварды

Из 4464 постов форвардный пост помечен у большинства каналов; медианная
доля форвардных постов — **80.0 % массовый слой, 91.7 % экспертный**
(см. `docs/08` §4).

> **ВЫВОД (confidence: высокий).** Форвард — **основной способ
> производства контента в нише**. Это не авторский контент, а
> перепечатка. Именно поэтому каналы ниши так быстро дублируют
> друг друга (см. `docs/02`).
>
> **ПРАКТИЧЕСКИЙ ВЫВОД.** «Контент-завод» в этой нише — это
> **технически тот же формат, что уже практикуют все игроки**.
> Вопрос не в формате, а в скорости и в источниках: кто первым
> читает blog вендора и первым публикует. При скорости перепечатки
> 7–8 минут (см. `docs/05`) окно на «оригинальность» — **минуты**.

## 6. Что это значит для контент-завода

| Измерение | Итог | Следствие |
|---|---|---|
| Доля t.me во всех ссылках | 39.0 % | Мониторить Telegram, а не СМИ |
| Доля блогов вендоров | 4.0 % | Прямой RSS вендоров = главный вход |
| Доля СМИ | 3.6 % | СМИ — не источник, а тема для цитирования |
| Доля сокращателей | 0.7 % | Терять трассируемость источника |
| Доля форвардов в постах | 80–92 % | Формат = перепечатка |
| @упоминания = реклама | да | Не использовать для карты источников |

**Прямые выводы:**

1. **Конвейер сбора** должен читать RSS/Atom блогов вендоров напрямую.
   Промежуточные агрегаторы добавляют задержку и не дают выигрыша.
2. **Скорость** — единственная защита от вытеснения: окно оригинальности
   измеряется минутами.
3. **Проверяемость** обязательна: 0.7 % ссылок идут через сокращатели,
   и их источник нужно раскрывать на этапе сбора, иначе ошибку
   невозможно отследить.
4. **Атрибуция** обязательна: ниша ссылается на источник (часто
   доменом, без имени автора). Это и норма этикета, и юридическая
   защита при претензиях правообладателей (см. `docs/07`, G10).

## 7. Ограничения

1. **Окно 15 суток** — мало для вывода о структуре источников;
   устойчивые выводы требуют 2–3 месяцев.
2. **37 каналов**, а не вся ниша (161 собранный канал).
3. **links.json обрезан на 1200 символов** — длинные посты могли
   потерять ссылки в хвосте. Затрагивает 4.8 % постов.
4. **Счётчик ссылок** считает вхождения, не уникальные посты.
5. **`x.com` (120 ссылок) не проверен** — доступ к X закрыт, домен
   фиксируется по URL, но содержание и время публикации неизвестны.
6. **Форварды из `fwd_name` не всегда заполнены** — часть форвардов
   приходит без имени, и такие посты могли не попасть в статистику.
