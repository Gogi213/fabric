## 2. Подтверждённые ошибки в картe источников

### E1. «Telegram — основной upstream (38–48 % ссылок)» — артефакт подписей

Доля `t.me` в ссылках RU-каналов: 1583 из 3868 (40.9 %). Из них:

| Вид ссылки | Ссылок | % всех ссылок |
|---|---|---|
| на **свой** канал («подписаться» в конце поста) | 1341 | 34.7 |
| на свой пост | 43 | 1.1 |
| приглашения `t.me/+…` | 58 | 1.5 |
| **на пост чужого канала** | **41** | **1.1** |
| на чужой канал без поста (партнёры, реклама) | 86 | 2.2 |
| боты | 14 | 0.4 |

**Цитирование постов другого Telegram-канала — 41 ссылка на 22 канала за две недели.**
Вывод «мониторить Telegram, а не СМИ» из этих данных не следует. Перепечатки
между каналами (docs/02) реальны, но они идут **без ссылок** — ссылочный метод
их не видит.

### E2. «Топ-12 доменов» — самоссылки каналов

`docs/04` §3 считает по всем 37 каналам сразу, включая EN и алиас:

| Домен | Ссылок | Откуда на самом деле |
|---|---|---|
| kod.ru | 337 | 336 — сам @d_code (свой сайт, а не «конкурент») |
| bleepingcomputer.com | 253 | 252 — канал @bleepingcomputer |
| thehackernews.com | 139 | 132 — канал @TheHackerNews |
| tldrnewsletter.com | 102 | 102 — @tldrtech |
| rozetked.me | 75 | 74 — @rozetked |
| github.com | 278 | 96 — канал @GitHub |

Плюс `technomedia` и `tehnochat` — один канал (251 идентичный пост), он посчитан
дважды: +362 ссылки (+6.1 %). Интервалы «[0.0; 17.1]» у этих доменов — не
«неустойчивость оценки», а признак одного канала-владельца.

Вывод про «сайтостроительного конкурента» (`docs/04` §3) снят.

### E3. «80–92 % постов — форварды» — подмена переменной

В `tools/production.py` столбец «форвард%» = `fw / max(f, 1)` — доля форвардов,
**не содержащих слов «новость/релиз/запуск…», среди форвардов**. В `docs/08` и
`docs/04` §5 она названа долей постов.

Фактически форвардов **90 из 2579 постов RU (3.5 %)**; медиана по каналам 1.9 %
(массовые 0.9 %, экспертные 11.8 %). Из 90: 30+ — рекламные (Альфа, Билайн,
Авито…), остальные — взаимные форварды экспертов (neuraldvig ← xor_journal,
denissexy ← seeallochnaya). Вживую на 6 каналах тоже 0–3 форварда на страницу.

Вывод «форвард — основной способ производства контента, формат = перепечатка»
(`docs/04` §5) снят. Перепечатка существует (docs/02), но не через форварды.

### E4. Классификатор рекламы: ноль настоящих erid, 105 ложных срабатываний

Регулярка `\b2[A-Za-z0-9]{15,25}\b` (`tools/production.py`) ищет строку из
16–26 символов. Настоящий erid короткий: `2VtzquZvQkb` — 11 знаков.
Совпадений с настоящими erid — **0**. Срабатывает она в **105 постах**, и все
105 — 19-значные ID твитов в ссылках `x.com/…/status/2101781576656847051`.

Вторая подмена: форвард без слов «новость/релиз/запуск/объявл» считается
рекламой. Эксперты форвардят друг друга (docs/02 §2.1), поэтому их «реклама»
раздута.

| Слой | Проектное ad% (docs/08) | По явной маркировке* |
|---|---|---|
| массовый | 2.6 % | 1.3 % |
| экспертный | 18.9 % | 1.0 % |

\* `erid=` в ссылке, слово `erid` в тексте, `#реклама`, `#ad`, «Реклама. Рекламодатель».
Постов с настоящей маркировкой — 64 из 2579.

Вывод «экспертный слой рекламирует в 7 раз активнее», «рекламная нагрузка
экспертов 18.9 %» и практический вывод про «вход через экспертный слой» —
**артефакт классификатора**. Разницы в маркированной рекламе между слоями нет.
Оговорка из `docs/06` §3.1 (немаркированную рекламу не видно) остаётся в силе.

### E5. «Первичный источник — блог вендора (confidence: высокий)» — измерено другое

Измерено: на что **ссылаются**. «Откуда взяли» не измерено: у 58 % постов RU нет
ни одной внешней ссылки-источника (осталось 42 % = 1080 из 2579 постов).

Внешние ссылки RU (1647) по корзинам, без своих сайтов, рекламы и t.me:

| Корзина | % внешних | % всех ссылок | каналов из 22 |
|---|---|---|---|
| Вендоры ИИ (openai, anthropic, claude, blog.google, qwen, yandex, apple…) | 14.7 | 6.3 | 21 |
| Код и модели (GitHub, HF, arXiv) | 13.7 | 5.8 | 17 |
| Соцсети/видео (X 118, YouTube 66, Reddit 12) | 12.1 | 5.1 | 20 |
| СМИ РФ (РИА, РБК, ТАСС, ИЗ…) | 7.2 | 3.1 | 13 |
| СМИ мир (Reuters, CNN…) | 4.1 | 1.8 | 14 |
| прочее (длинный хвост) | 46.5 | 19.8 | 21 |

Вендоры — крупнейшая **именованная** группа, это устояло. Не устояло:
«блог вендора — единственный первоисточник» и «СМИ и соцсети в цепочке не
участвуют» (`docs/04` §3.1): X — самый широко цитируемый домен (19 из 22 каналов;
по числу ссылок второй после GitHub), РИА/РБК/ТАСС/Reuters — по 6–9 каналов. Вендорный бакет в `docs/04`
(5.0 %) включает `claude.ai`, `chatgpt.com` — это продукты, не блоги.

### E6. Три разных набора процентов в одном документе; файл не воспроизводится

`docs/04`: t.me = 48.2 % (§2), 38.2 % (§3), 39.0 % (§6); вендоры 5.0 % (§2) и
4.0 % (§6, §05). `data/sourcemap.json` не создаётся ни одним скриптом репозитория
(`sources3.py` пишет в stderr и другие корзины). Числа из него проверить
нельзя, только сверить суммы (3813 сходятся).

### E7. Мелкие, но влияющие на доверие

- `CodeCamp` (7 форвардов у xor_journal/neuraldvig/exploitex) классифицирован
  как «новостной источник»; по содержимому это канал-источник историй
  («Codex сжёг $80 000», «Oracle уволил тысячи»). Реальные Telegram-upstream в
  выборке — такие небольшие каналы, а не вендоры.
- Жёсткие пути `C:/visual projects/parser/…` в 16 скриптах. Заменены на пути
  от корня репозитория (поведение не менялось).

## 4. Полнота

### 4.1. Что и за какие даты собрано

| Набор | Каналов | Постов | Период | Дублей id |
|---|---|---|---|---|
| posts.json | 22 (+алиас) | 1600 | 22–29.09 (7 сут) | 0 |
| posts_en.json | 14 | 957 | 22–29.09 | 0 |
| links.json | 22 + 14 (+алиас) | 4464 | 15–29.09 (14 сут) | 0 |
| reactions.json | 22 | 4126 | 14.04–30.09 | 0 |

Независимых каналов: **36**, не 37.

### 4.2. Глубина по каналам: периоды несопоставимы

`reactions.json` — по ~200 постов на канал, поэтому глубина зависит от частоты:
7–168 суток, медиана 32. **Массовые — 13 сут, экспертные — 89 сут.**
Сравнение слоёв по реакциям идёт на разных отрезках времени и разных
событиях. В `links.json` 18 из 22 каналов дают посты в ≥14 из 15 суток;
редкие (seeallochnaya, denissexy, ai_newz, tlive) — 7–12.

### 4.3. Посты: собираются только с текстом

По диапазону id за 14 суток собрано **медиана 69 %** (от 44 % у technomotel до
96 % у d_code). Остальное — сообщения без текста (картинки, альбомы, опросы)
или удалённые. «13.0 и 2.7 поста/сутки» — это посты **с текстом**;
сообщений в сутки у массовых 20.1 против 13.9. Для оценки нагрузки фабрики
нужна вторая цифра.

### 4.4. Реакции

В файле 22 канала, данные есть у **20**. У `tlive` и `NeuralShit` реакций нет:
вживую (30.09) на их страницах нет блока реакций совсем (у xor_journal — на
18 из 18 постов). Это свойство каналов, а не ошибка парсера; открытый вопрос
из `docs/06` §4 закрыт. Для анализа реакций доступно **20 каналов и 3692 поста**
(не «22» и «4124»). Посты на пределе 12 типов реакций: 71 (1.7 %).

### 4.5. Каналы: выборка против каркаса

| Каркас | Размер | Из выборки внутри |
|---|---|---|
| telegram.menu «Технологии/IT» | 58 каналов, 50.8 млн (в `docs/07`: 43.4 млн) | 12 каналов, **34 % подписчиков** |
| tgme.app поиск (9 запросов) | 321 | 2 |
| market_size.json | 921 (762 с подписчиками, 629 активны за 14 сут; у 160 дата неизвестна) | — |

В каркасе A остались вне выборки 46 каналов (@technolavka, @typespace,
@media1337, @provod, @techmedia, @kostylofficial… по 1.1–1.5 млн). Причина —
критерий отбора не формализован (`docs/01` §1.10.1). В каркасе B **13 %
(41 из 321) — боты** по имени; медиана без ботов 27.5K вместо 30.2K.
README («100–250 каналов, медиана 69K») и `docs/07` §4.1 («300+, медиана 30K»)
противоречат друг другу; обоснования цифры 69K в репозитории нет.

### 4.6. Домены-источники: карта не насыщена

RU, внешние ссылки: 2285, корневых доменов 560, **327 встретились один раз**.
Оценка Гуда–Тьюринга: 14 % ссылок ведут на домены, которых в карте нет.
Кривая по каналам не выходит на плато (22-й канал добавил ≈18 новых доменов),
по суткам тоже (15 суток — 560, рост продолжается). Устойчиво только то, что
цитируют много каналов: 122 хоста ≥3 каналов, 55 ≥5.

### 4.7. Мелкие расхождения в счёте

- `posts_en.json`: 957 постов в файле, в документах 936 (фильтр не описан).
- `subs.json` хранит 22 канала + служебный ключ `_fetched`.
- `docs/04` §3: «1087 доменов»; пересчёт даёт 1076 хостов.
