## Главные ошибки по влиянию на решение о контент-заводе
1. **Разрыв ER между слоями — это размер канала, а не режим работы.** rho(log подписчиков, ER) = −0.84; при контроле размера эффект слоя ×0.61 [0.26; 2.18]. На этом держатся центральная рекомендация 08 §6/§8.2 («экспертный режим: ×3.4 просмотров на пост при ×4.8 меньшем бюджете») и шаг README «ER известен, осталось узнать TPR». Для канала на 10–50K ER не измерен: минимальный канал выборки 52.6K.
2. **Реклама 2.6 / 18.9 % — артефакт классификатора.** Из 150 настоящих erid не пойман ни один; 105 срабатываний — ID твитов; к рекламе отнесены форварды. По явной маркировке ≈3 % в обоих слоях, p = 1. Вывод «вход через экспертный слой» теряет основание.
3. **«4.8 раза» неустойчиво, «автоматизация обязательна» не измерено.** В зависимости от окна и определения слоя отношение 2.9–5.8, частоты образуют континуум. Массовые каналы работают по «человеческому» графику: 92 % постов днём, в выходные ×0.55.
4. **Расписание.** Пик слабый: 36.9 % постов против 33 % при равномерном распределении. Ночь не пуста. Рекомендованный слот 08–11 нагружен почти как пик (26.8 % против 30.1 %). Измеримый сигнал обратный: посты 18–23 UTC набирают +7…+14 % просмотров, потому что дольше остаются последними в канале.
5. **Длина.** «Следствие частоты», «бимодальность» и «эмодзи как маркер» опровергнуты. «Длина не влияет на просмотры» устояло (TOST ±1 %), но просмотры для этого вопроса — неподходящая метрика.
6. **Методология.** Утверждение о «несортированных страницах» ложно. Таблица §1.5 относится к эмбеддингам, а не к TF-IDF. Порог 0.80 «откалиброван» на двух парах. Таблица объёмов считает посты дважды. Протокол §1.11 в 08 и README не применён. Воспроизведение сломано (subs.json перезаписывается, tldrtech обрезан max_pages).
