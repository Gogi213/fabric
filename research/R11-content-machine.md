# R11. Контент-машина: как выходить раньше других в своём стиле и ритме

**Основа:** R3 (скорость, сетки), R4 (окно по темам), R5 (что заходит), R8 (инструменты, юридика),
теневой прогон `tools/r11_shadow.py` (замер в реальном времени — §5).

## 1. Где машина может быть первой (окно по темам, из R4)

Лаг — медиана: первый пост в Telegram минус самая ранняя публикация в СМИ.

| Тема | Лаг каналов от СМИ | Окно машины | Откуда брать |
|---|---|---|---|
| Apple, гаджеты, софт, роботы, OpenAI-инциденты | 7–18 ч | **часы — главная возможность** | англоязычные тех-СМИ: MacRumors, 9to5Mac/Google, The Verge, Tom's Hardware, Notebookcheck, Engadget, The Decoder, Electrek, GSMArena |
| ИИ-индустрия | ~2 ч | десятки минут – часы | сайты и блоги вендоров, The Decoder, TechCrunch, HN |
| Главные релизы (модели, консоли) | 82 мин; в 11 из 31 случаев Telegram первым | минуты | сайты вендоров, sitemap, X-аккаунты вендоров и инсайдеров, HN |
| Регулирование и сервисы РФ | 14 мин | минуты; конкуренция с перепечатчиками СМИ | Интерфакс, ТАСС, РИА, Коммерсантъ, РБК, Известия, CNews |
| Нейросети: инструменты и лайфхаки | в СМИ нет (28 из 34) | своя находка | Product Hunt, GitHub Trending, HN Show, Reddit r/LocalLLaMA и r/singularity, X |
| Курьёзы, вирусное | Telegram раньше СМИ | — | X, Reddit, TikTok — вне измерения |

## 2. Архитектура

```
Источники ──► Сбор (опрос 30–60 с) ──► Склейка дублей ──► Отбор ──► Рерайт в стиле ──► Картинка ──► Публикация ──► Зеркала
 RSS/sitemap      очередь событий        эмбеддинги,       оценка       LLM, правила       своя/         Bot API       VK, Max
 HN/PH/GitHub                            «уже было?»       «хит?»       стиля              лицензия
 X (API)
 каналы-конкуренты (только как сигнал)
```

1. **Сбор.**
   - Ленты из R4 с точным временем: у OpenAI поправка +7 ч, у Anthropic — `sitemap.xml`.
   - HN, Product Hunt, GitHub releases.
   - X — через платный API: ключевые аккаунты вендоров и инсайдеров.
   - Каналы-конкуренты: 30–40 самых быстрых из R3 через `t.me/s/`, только как сигнал «сюжет пошёл».
     Их текст не копировать.
2. **Склейка.** Эмбеддинги той же модели, что в исследовании: порог 0.80 к первому элементу сюжета
   (якорю), окно 48 ч. Проверка «уже публиковали» — по истории своих каналов.
3. **Отбор.** Тема (классификатор по 16 темам R4) плюс признаки «хита»: крупный бренд, связь с РФ,
   число источников за последний час, движение у конкурентов. Порог и квоты по темам задаёт редакция.
4. **Рерайт в стиле.**
   - Заголовок и 1–3 предложения, до 300 знаков (R5: короткие посты — +16 % реакций).
   - Без капса, не больше 1–3 эмодзи.
   - Факты своими словами, ссылка на источник. Перевод близко к тексту запрещён (R8).
5. **Картинка.** Генерация или пресс-кит с разрешением. Фото из источника не копировать:
   фото — самые частые иски (R8).
6. **Публикация.** Bot API в свой канал. Сервер — за рубежом (R8). Зеркала — VK, Max (R10).
7. **Человек в контуре.** Одна кнопка «опубликовать / поправить / отклонить» в боте-редакторе.

## 3. Бюджет задержки (цель — ≤5 мин от появления в источнике)

| Шаг | Время |
|---|---|
| Опрос источника | 0,5–1 мин (интервал опроса) |
| Склейка и отбор | <10 с |
| Рерайт LLM | 5–20 с |
| Картинка | 10–60 с (генерация) или 0 (шаблон) |
| Проверка человеком | 1–5 мин (по желанию; для тем с окном в часы можно включать всегда) |
| Публикация | <5 с |

## 4. Стиль и ритм

- **Объём.** У ниши: массовые — 6 постов в сутки, AI-медиа — 2,3 (R1–R2).
  Для канала 1 разумно 6–12 в сутки, сделанных машиной, плюс 1–2 своих.
- **Время.** Пики не нужно ловить. Просмотры почти не зависят от часа; ночью и поздно вечером
  пост дольше остаётся верхним в ленте (+2–6 %). Главное — публиковать сразу, как пришла новость.
- **Форварды не использовать.** Свой пересказ набирает больше: форвард — 0,91 от медианы канала (R5).
- **Скорость окупается ростом подписчиков, а не просмотрами поста** (R5). Поэтому её надо проверять
  экспериментом: канал 1 против канала 2 (R9).
