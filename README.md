# Telegram-контент-завод: исследование ниши IT/AI

**Дата данных:** 2026-09-29 / 30
**Статус:** подготовка. **Конвейер не реализован** — документы описывают
измеренную нишу и то, что осталось неизвестным.

---

## TL;DR

**Ниша маленькая, но не пустая.** Порядка **100–250 медиа-каналов**,
медиана 69K подписчиков, половина рынка в полосе 10K–50K.
Это реалистичная ниша для входа.

**Деньги в Telegram-рекламе лежат не в tech.** Топ рекламодателей —
gambling, trading, casino, betting, crypto. В нише tech всего 4
рекламодателя в выборке TG.ME. **Прямая продажа рекламных слотов в
AI-нише — слабый бизнес-план.** Это главный открытый вопрос.

**Каталоги врут.** Топ категории «tech» на TG.ME — VPN-фермы; канала
@whackdoor (1.59 млн) там нет вообще. Рабочие источники — telegram.menu
(лидеры) и поиск tgme.app (хвост).

**Производственный режим измерен.** Массовый слой — 13.0 постов/сутки
(391/мес), экспертный — 2.7 постов/сутки (82/мес). Пик публикаций
13:00–17:00 UTC. Ночные смены не нужны.

**ER двуполюсный.** Экспертный слой — 13.3 % просмотров на подписчика,
массовый — 3.9 %. Массовый публикует в 4.8 раза больше, но отдаёт
в 3.4 раза меньше просмотров на пост.

**Скорость решает.** Лаг между крупнейшими каналами — **7–8 минут**.
Окно оригинальности — минуты, а не часы.

**Реакции доступны и измерены — 1.25 млн штук.** После статистического
аудита устояло: разрыв слоёв **x5.7**, пост **короче 300 символов**
(+17.8 п.п., CI [+13.7, +22.0]), **анонс релиза модели — антипаттерн**
(x0.54, q<0.001), Google/Gemini-новости x0.43, локальное РФ x1.45.
Не устояло: «резать частоту» (отозвано), «юмор ×1.84» и «взломы ×1.51»
(не переживают FDR), «картинка +4.2 п.п.» (шум).

**Главный блокер — цена рекламы (TPR).** Без неё юнит-экономика
не считается. Второй блокер, добавленный аудитом: **в выборке нет ни
одного автоматизированного канала**, а эффект частоты не установлен
причинно.

## Три отозванных вывода

Чтобы их не использовали повторно:

1. **«Новости впервые появляются в X»** — снят. X недоступен, время
   первого появления не измерено ни для одной истории.
2. **«Медиана длины поста ≈ 1200 из-за обрезки»** — снят. Медиана 376
   (обрезанный) против 381 (полный); обрезка задевает 4.8 % постов.
3. **«6 валидных историй в таймлайне»** — снят. Валидных 3, и одна из
   формально быстрых имеет отрицательный лаг (ложное совпадение).

Подробно: [`docs/06-errors-and-corrections.md`](docs/06-errors-and-corrections.md).

## Следующий шаг

**Одно действие разблокирует всё остальное:** запросить ставки (TPR)
у 8–12 админов каналов полосы 10K–50K и/или купить минимальный тест
в официальном Telegram Ads.

Зная ER (измерен: 13.3 % для экспертной модели) и посты/сутки
(измерено: 2.7), остаётся единственная неизвестная — сколько стоит
один просмотр. После этого считается юнит-экономика, и только после
неё имеет смысл обсуждать техническую фабрику.

## Воспроизводимость

```powershell
# ядро анализа (работают на уже собранных данных)
python tools/analyze2.py
python tools/sources3.py
python tools/timeline3.py
python tools/production.py

# поведенческий анализ
python tools/behave_crawl.py         # сбор реакций (требует сети, ~9 мин)
python tools/behaviour.py
python tools/behaviour_within.py

# статистическая проверка
python tools/stats_audit.py
python tools/stats_addendum.py

# сбор рынка (требует сети)
python tools/market_size.py
python tools/market_deep.py
```

**Зависимости:** `requests`, `beautifulsoup4`, `scikit-learn`,
`sentence-transformers` (только для `cross2.py`).

**Все выводы в документах** сопровождаются доверительными
интервалами и явно помечены как ИЗМЕРЕНО / ВЫВОД / ГИПОТЕЗА.
Статистический протокол проекта: [`docs/01`](docs/01-methodology.md) §1.11.
